```python
    secret = os.getenv("JWT_SECRET_KEY")
    if not secret:
        # Defense in depth — AUTH-08's startup check should already have
        # prevented this. Never leak the underlying reason to the caller.
        raise HTTPException(status_code=500, detail="Could not process login. Please try again later.")

    return jwt.encode(payload, secret, algorithm=_JWT_ALGORITHM)
```

PyJWT. **AF-05's correction is accurate.** T-03's fail-fast startup check is protecting an
already-real, already-merged consumer, not a still-hypothetical one.
