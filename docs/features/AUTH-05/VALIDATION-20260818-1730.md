## Fix under validation

- Added `login(email, password)` to `frontend/src/services/userApi.js` — calls
  `POST /api/auth/login` via the shared axios client (through `normalizeError`, matching the
  rest of the module's error-handling convention).
- `frontend/src/components/LoginScreen.jsx` now imports `login`/`setAuthToken` from
  `userApi.js` instead of the deleted `userAuthService.js` mock; on success it persists the
  token via `setAuthToken` and calls `onLoginSuccess(token)`; on any rejection it shows a
  generic `"Invalid email or password. Please try again."` message (no raw error surfaced).
- `frontend/src/services/userAuthService.js` deleted entirely — the mock login path no longer
  exists anywhere in the tree.
- `frontend/src/components/__tests__/LoginScreen.test.jsx` and
  `frontend/src/components/__tests__/LoginForm.test.jsx` updated to mock `userApi.login`
  instead of the deleted module.
- `App.jsx` itself is untouched by this fix (confirmed — diff is scoped to `userApi.js`,
  `LoginScreen.jsx`, the two test files, and the deletion of `userAuthService.js`).
