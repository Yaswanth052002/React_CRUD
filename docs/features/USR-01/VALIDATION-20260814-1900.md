     open and the message renders inline.

  path (PLAN.md T-06 Notes column explicitly claims "Covers ... TC-10-TC-15").

  (`Users.crud.test.jsx:174`) is actually the **add-user** failure path (matches

- Ad-hoc verification result: the throwaway spec **passed** — `Users.jsx`'s `handleFormSubmit`
  (Users.jsx:135-153) is a single shared function for both create and edit that sets
  `setFormError(err.message)` in its `catch` regardless of `modalMode`, so the edit-failure path
  is almost certainly correct at runtime. This downgrades the severity from "functional defect" to

  test file's own local sequence rather than cross-checking each block's title against

  "TC-13" while true TC-13 (edit failure) was dropped.
- Recommended fix: add one test to `Users.crud.test.jsx` mirroring TC-14 (edit-success) but with
